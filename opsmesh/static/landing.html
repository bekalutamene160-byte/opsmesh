🛡️

Two-gate approval

Every email is reviewed twice: once for evidence sufficiency (Gate 1), once before sending (Gate 2). Nothing goes out without your sign-off.

🔍

Grounded in evidence

The AI researches each lead with real web search (Exa) + LLM (Groq GPT-OSS 120B). Every claim in the email must cite evidence — the Critic verifies it.

⚡

Crash-proof

Runs are persisted to Postgres at every step. If the server crashes mid-run, it resumes exactly where it left off — no duplicate sends, no lost work.

📊

Full observability

16-state state machine, structured JSON logging, 8 ops metrics, audit trail. You always know what happened, when, and why.

🔌

Real integrations

Groq for LLM, Exa for research, Resend for email, HubSpot for CRM. All configurable via env vars — swap providers without touching code.

🔒

Secure by default

Google OAuth, workspace isolation, HMAC webhooks, payload-hash approval binding, email kill switch. Security is baked in, not bolted on.
